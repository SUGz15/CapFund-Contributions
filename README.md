##Overview

C-Cash is a mobile-first cashless transaction application built using **Ionic Angular**. The system supports employee and kiosk transaction workflows through QR-based interactions, transaction monitoring, reporting, and administrative management tools.

This project was developed as part of a collaborative academic and development effort. My primary role focused on:

- Frontend Development
- Mobile UI Implementation
- REST API Integration
- Angular Service Integration
- Transaction Flow Development
- Admin Feature Development

---

##Key Features

### Employee Features
- QR Code Generation
- Transaction History
- Current Balance Viewing
